# Neuro-symbolic tokamak-control software

This package contains the authoritative JOSS-format software-paper source and
its review PDF. It reports repository capabilities together with explicit
boundaries for external-code, nonlinear gyrokinetic, experimental-data,
facility-control, and runtime-admission evidence.

The manuscript is a review draft and has not been submitted. See [`BUILD.md`](BUILD.md)
for the reproducible local build and `submission_metadata.json` for machine-readable
status.
