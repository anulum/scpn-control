# SPN-to-SNN tokamak-control architecture

This package contains the longer RevTeX architecture manuscript describing the
SPN-to-SNN compilation and control stack. Quantitative timing is bound to the
committed CI-runner and workstation reports and is not an end-to-end facility
latency guarantee. Experimental validation, hardware deployment, and external
solver equivalence remain explicitly outside the admitted evidence.

The manuscript is a review draft and has not been submitted. See [`BUILD.md`](BUILD.md)
and `submission_metadata.json`.
